
A modern browser-based code editor that allows users to write, edit, and run code directly in the browser. The project provides a clean and responsive interface with support for multiple programming languages, syntax highlighting, and real-time preview/output.

---

## Features

* Live code editing
* Syntax highlighting
* Support for diffrent - diffrent Programming languages
* Real-time preview/output
* Responsive user interface
* Auto-update preview when code changes
* Reset/Clear code functionality
* Dark mode friendly UI

4. Run the development server:

npm run dev

5. Open in browser:

---

## How It Works

1. User writes code in the editor.
2. The application stores the current code in state.
3. Whenever the user updates code, the preview/output updates automatically.
4. HTML, CSS, and JavaScript are combined and rendered in an iframe or output window.
5. Errors are displayed if the code is invalid.
